# Workflow do GitHub

Sempre antes de fazer qualquer correção, atualização ou modificação no código, **obrigatóriamente** verifique o status do repositório e faça o commit e push das últimas alterações para o GitHub. 
Só ignore essa regra se o usuário solicitar explicitamente o contrário.

Passo a passo antes de iniciar novas tarefas:
1. `git add .`
2. `git commit -m "chore: save state before next task"` (ou uma mensagem apropriada do que foi feito)
3. `git push`
